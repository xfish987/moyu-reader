# UI B 架构

## 方向

“雾层书房”采用稳定内容面与克制半透明外壳：背景只在 L0 提供氛围，工具层使用细轮廓，正文保持高不透明度。界面强调桌面工作流，不做营销式首屏。

## 分层

1. `BackgroundLayer`：主页与阅读器各自读取独立偏好。
2. `AppShell`：标题栏、导航轨、主工作区和通知。
3. 页面层：书架工作区与阅读工作区复用既有业务回调。
4. 内容层：封面、正文、表单、菜单和弹窗保持稳定表面。

## 状态策略

继续使用 `useStoredState` 和现有磁盘存储。新增 `reader:appearance-v2` 存小型偏好；背景图片由主进程复制到 UI B userData，再只保存返回的资产 URL 与元数据。
