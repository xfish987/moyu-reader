# 墨读阅读器 v2.5.0 交接文档

更新时间：2026-09-03

## 产品组成

- Windows 桌面端：Electron + React + Vite，负责本地 TXT/EPUB 阅读、书架、笔记、AI 翻译、名词库和云同步。
- 墨读书城：`cloud-server/web` 静态前端，提供共享书城、搜书制作、TXT 转 EPUB、分卷维护和账户管理。
- 云服务：`cloud-server/server.mjs`，数据默认位于 `/var/lib/moyu-reader`；搜书与 EPUB 制作分别调用独立容器。
- 生产地址：`https://modu.cxnnn.cn/moyu-reader-cloud/`。

## 核心用户闭环

### 搜书制作 / EPUB 制作

入口为书城顶部两个独立图标。用户提交后立即看到排队/进行中状态、阶段、百分比和预计完成时间；任务及输入文件按账户保存在服务器，关闭页面或服务重启不会丢失。顶部“制作记录”在打开时每 3 秒刷新；失败任务可直接重试，完成任务可下载，并通过下载按钮旁的下拉操作放到阅读器。

### 章节翻译

阅读器工具栏提供“开始翻译”和“名词库”，正文空白处右键也可打开翻译、翻译设置、名词库和重新翻译。未配置 AI 时自动打开 AI 设置。翻译仅处理当前章节，并严格按源段落建立对应关系；支持简体/繁体、双语/仅译文，以及韩国 Web 小说、日本轻小说、英文网文和一般文学策略。

底部翻译伴读栏持续显示状态，可开始、停止、重新翻译、预译下一章或打开名词库。译文缓存、设置和名词库按账户同步；再次阅读可直接显示既有译文，修改名词库后会提示译文已过期，用户可主动重新翻译。

### 名词固定

选中一个名词后右键“名词固定”，AI 生成固定译名并加入库。选中整个段落时，AI 会批量提取人名、地名、组织、称号、技能和关键专名。名词库中的原文和中文译名均可编辑、删除；翻译章节时完整名词库以最高优先级送入提示词。

### 多系列 / 多卷书籍

书城上传支持最多 200 个 TXT/EPUB 文件，并为每个文件保存系列/分组与卷标。书籍详情页为作者提供“追加新卷”和“整理分卷”，可编辑系列及卷标、调整传入顺序、删除单卷或更新连载状态；读者可以下载单卷或打包下载全部。服务端校验整理请求必须保留全部文件，避免前端漏传导致静默丢卷；重复或失败上传会清理孤儿文件。

### 登录与账户数据

默认会话不过期，仅在主动退出、修改密码或删除账户时失效。账户导出包含同步数据、个人书库、章节翻译、名词库、制作历史、想法和评价。清空或删除账户会同步清理快照、翻译数据、制作记录及其文件。

## 生产部署与回滚

生产目录为 `/opt/moyu-reader-cloud`，部署前先复制该目录做带时间戳备份，然后更新代码并执行：

```sh
cd /opt/moyu-reader-cloud
docker compose up -d --build moyu-cloud
docker compose ps
```

验证 `/moyu-reader-cloud/health` 返回 200，并确认容器为 healthy。回滚时将备份目录中的代码恢复到生产目录，再重新 build/up；不要覆盖 `/var/lib/moyu-reader`。邀请码等敏感值通过服务器环境变量 `INVITE_CODE` 注入，不写入仓库。

## 数据与维护注意事项

- `users.json` 使用串行原子写入；部署时必须保留数据卷。
- 制作历史和成品默认长期保留，以满足跨会话下载；容量治理应通过后续明确的用户删除入口完成，不应恢复静默过期删除。
- 修改翻译缓存结构时需保留账户、书籍、章节、目标字形和翻译策略维度，避免不同译文互相覆盖。
- 新增分卷维护能力时，应继续以文件 ID 为主键，不以可编辑的系列名或卷标寻址。
- 当前书城是两人共同维护的私人书城，任何已登录用户均可删除任意书籍；删除会同时移除全部分卷和封面，前端必须保留明确确认。
- 每次任务的固定最后一步：更新本交接文档，记录新功能、入口、数据结构、部署变化、验证结果和仍需关注事项；随后再提交并推送该文档。
