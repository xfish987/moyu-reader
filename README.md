# 墨读阅读器

墨读是一款面向 Windows 和 Android 的本地 TXT / EPUB 阅读器。书籍内容、阅读进度和笔记默认保存在本机，不需要注册账号。只有当用户主动使用 AI 功能时，应用才会把当前阅读位置之前的相关正文片段发送给用户自行配置的 AI 供应商；不会发送后续章节。

## 下载与使用

1. 打开项目的 **Releases** 页面。
2. Windows 免安装使用下载 `MoyuReader-版本号.exe`，安装使用下载 `MoyuReader-版本号-Setup.msi`。
3. Android 下载 `MoyuReader-版本号-android.apk`，允许浏览器或文件管理器安装未知来源应用后完成安装。
4. 在应用中导入 TXT / EPUB；Android 会打开系统文件选择器，不需要授予“管理所有文件”权限。

当前发行包没有商业代码签名。Windows SmartScreen 首次运行时可能显示安全提示，请确认文件来自本项目的 GitHub Release 后选择继续运行。

Android 版使用独立发布密钥签名。Android 12 及更早版本声明只读存储权限；Android 13 及更高版本使用系统文件选择器授权单个书籍或背景图片，不申请宽泛的全部文件访问权限。导入的书籍和背景会保存为应用私有副本，重启后仍可阅读。

## Android 触控操作

- 点按书籍立即进入全屏阅读。
- 阅读页左侧点按上一页，右侧点按下一页；音量上键上一页，音量下键下一页。
- 点按正文中间区域，同时显示或隐藏顶部工具栏、底部进度条和 AI 陪读状态栏。
- AI 陪读开启后，“停止 AI 陪读”只出现在顶部的“更多”菜单。
- 书脊在按住时短暂展开封面，松开后打开阅读；近期书籍继续使用正面封面。
- 管理视图点齿轮进入/退出排序模式；长按书封打开分类、修改封面、重新定位和删除本地副本操作页。
- Windows 的资料卡、字典和陪读独立窗口在 Android 上改为应用内全屏页面。

## 主要功能

- TXT 与 EPUB 本地阅读
- 文件夹递归扫描和单本书导入
- EPUB 书名、作者、目录与封面解析
- EPUB 书目信息与内置封面磁盘缓存，重复启动时无需重新解包
- UTF-8、GB18030 / GBK、Big5、UTF-16LE、UTF-16BE 文本支持
- 大型 TXT 分块加载、目录识别和全文搜索
- 阅读进度自动保存与继续阅读
- 基于内容指纹识别书籍，文件改名或移动后可继续关联原阅读数据
- 书架搜索、排序、阅读状态筛选与批量管理
- 字体、字号、行距、段距、字距、页边距和文字透明度设置
- 纸白、护眼、夜间三种阅读主题
- 正文简体 / 繁体离线转换（不修改源文件）
- 独立书签、三色高亮、笔记编辑、Markdown 与分享图导出
- 书架分类、自定义封面、窗口置顶、沉浸阅读与老板键（F10）
- 文件拖放导入、Windows“打开方式”、窗口最大化与双击标题栏
- 全书搜索最多展示 5000 处匹配，达到上限时会明确提示
- 防剧透资料回顾：选中人物、物品、地点、组织、能力或事件名称后，右键可“生成资料”（仅总结当前位置之前已读的内容）或“查看资料”（已有资料卡时直接打开，不消耗 token）
- 每本书独立的“设定集”伴侣窗口：与阅读窗口并排互不遮挡，吸附跟随阅读窗移动，可收起为吸附在阅读窗右缘的悬浮图标，窗口大小位置自动记忆
- 资料生成是全自动后台任务：本地检索与 AI 生成依次排队执行，任务图标中查看每个任务的阶段（排队 / 检索中 / 排队生成 / 生成中），完成或失败时窗口顶部通知，全程不影响阅读和浏览设定集
- 长书上下文节制：检索命中全程均匀采样，按信息密度选取片段；增量更新只发送上次进度之后的新片段，显著节省 token；输出截断自动修复，任何情况下都能显示资料卡
- 设定集可按人物、物品、地点、组织等类型筛选，并按势力、持有者或上级区域自动分组；窗口内搜索名称、别名与资料内容，回车直达
- 关系索引会在两侧同步呈现：人物页能看到其物品与所属势力，物品和地点也保留在各自的完整索引中
- 人物卡详细整理与主角的关系、初识经过、关系网和身份；物品卡整理归属、获得经过与用途；地点卡整理位置、内容、相关人物与事件
- 别名与昵称关联：右键“关联到已有资料”通过可搜索的选择器快速归并，卡片上可直接添加别名，误关联的别名右键即可移除并记住“并非同一对象”
- 资料卡可删除；早期版本的损坏缓存卡会自动本地修复，不消耗 token
- 同一资料只在更后阅读进度再次查询时更新，不会读取未来章节
- 字典百科：划选文字右键“字典百科”，AI 结合章节上下文解说；独立窗口保存本书全部解释记录，可继续追问；消息支持 Markdown 渲染、复制、编辑重问、删除与重新生成，整条解释记录也可删除，会话列表可折叠
- AI 陪读：开启后每读到新章节自动后台总结（无章节划分的书按约 5000 字分段），乱序跳章也能按剧情顺序正确插入，中间漏读的章节会明确标注缺口；章节截断自动修复、空回复自动重试
- 剧情梳理：设定集内的独立栏目，把时间点、地点、人物、事件、得失与悬念整理成时间线；可独立搜索，人名地名可点击跳回资料卡
- 剧情提问：独立聊天窗口，自动携带书名作者、全部剧情梳理与设定集名单，严格按已总结进度回答、不剧透；会话可新建、重命名、删除，消息可复制、编辑重发、删除、重新生成
- 窄屏自适应：窗口过窄时工具栏次要图标自动收纳进溢出菜单，加宽后自动展开
- 书架首页 AI 设置，支持 Kimi 和 OpenAI Chat Completions 兼容接口、多个供应商方案、模型拉取与手动模型设置
- AI 请求错误诊断，显示请求阶段、HTTP 状态码、错误码、空回复、审核响应与输出截断
- 阅读数据导入、导出和自动备份

## 数据与备份

阅读进度、笔记、分类、自定义封面、每本书的设定集和人工身份规则保存在 Electron 的 Windows 用户数据目录下：

```text
%APPDATA%\<应用名称>\data\reader-data.json
```

应用写入数据前会在同目录的 `backups` 文件夹生成备份，并保留最近 10 份。书架顶部的导入/导出按钮可以生成可迁移的 JSON 备份。

AI 供应商配置在 Windows 另存于同一数据目录的 `ai-settings.json`，Android 则保存在应用私有数据中。API Key 在 Windows 使用系统安全存储加密，在 Android 使用 Android Keystore 的 AES-GCM 密钥加密；界面只能看到“已保存”状态，无法读回 Key。阅读数据导出不会包含 API Key。供应商 URL 默认必须使用 HTTPS，仅本机 `localhost` / 回环地址允许 HTTP；应用会拒绝携带 Key 的 HTTP 重定向。Android 的模型拉取和对话请求使用原生 HTTP 通道，不受 WebView CORS 限制。

“生成资料”会把已读范围内命中的片段、已确认的名称关联规则和所选名称发送到当前 AI 供应商（增量更新时还会附带上一份资料卡的内容）。该功能不会进行外部资料检索。不同供应商如何保存和处理请求数据，取决于用户选择的供应商政策。

从书架移除书籍或删除源文件时，笔记、书签和进度不会被静默删除；孤立笔记仍会出现在笔记库中，并可继续编辑或导出。

从旧版本升级时，应用会自动把原有 `localStorage` 数据迁移到新的磁盘存储中。

> Windows 版不会复制原始 TXT / EPUB 文件。文件在已扫描目录中改名或移动后，刷新书架即可重新识别；目录外的文件可在“整理书籍”中选择“重新定位”。Android 版通过系统选择器导入应用私有副本，因此删除本地副本不会修改系统中的原文件。

## 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `←` / `A` | 向左翻页 |
| `→` / `D` | 向右翻页 |

## 本地开发

需要 Node.js 22 或更高版本。

```powershell
corepack enable
pnpm install
pnpm test
pnpm run dev
```

构建前端：

```powershell
pnpm run build
```

构建 Windows 便携版 EXE：

```powershell
pnpm run dist
```

构建结果位于 `release/MoyuReader-版本号.exe`。

构建 Android APK（需要 JDK 21 和 Android SDK 36）：

```powershell
npm run android:apk
```

正式 APK 通过 `MOYU_ANDROID_KEYSTORE`、`MOYU_ANDROID_STORE_PASSWORD`、`MOYU_ANDROID_KEY_ALIAS` 和 `MOYU_ANDROID_KEY_PASSWORD` 四个环境变量注入签名配置；签名文件和口令不应提交到仓库。

## 项目结构

```text
electron/    Electron 主进程、Windows 文件读取、持久化与系统窗口接口
android/     Capacitor Android 工程、音量键与 Keystore 原生桥接
src/         React 界面、移动端平台接口和 TXT / EPUB 阅读器
assets/      应用图标
test-*       大文本分块、多编码、繁简转换与资料身份规则回归测试
```
