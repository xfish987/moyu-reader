# 墨读阅读器

墨读是一款面向 Windows 的本地 TXT / EPUB 阅读器。书籍内容、阅读进度和笔记默认保存在本机，不需要注册账号。只有当用户主动使用“查看资料”时，应用才会把当前阅读位置之前的相关正文片段发送给用户自行配置的 AI 供应商；不会发送后续章节。

## 下载与使用

1. 打开项目的 **Releases** 页面。
2. 下载最新版本的 `MoyuReader-版本号.exe`。
3. 双击运行，无需安装。
4. 点击“添加书籍”选择 TXT / EPUB，或点击“选择目录”扫描整个书籍文件夹。

当前发行包没有商业代码签名。Windows SmartScreen 首次运行时可能显示安全提示，请确认文件来自本项目的 GitHub Release 后选择继续运行。

## 主要功能

- TXT 与 EPUB 本地阅读
- 文件夹递归扫描和单本书导入
- EPUB 书名、作者、目录与封面解析
- EPUB 书目信息与内置封面磁盘缓存，重复启动时无需重新解包
- UTF-8、GB18030 / GBK、Big5、UTF-16LE、UTF-16BE 文本支持
- 大型 TXT 分块加载、目录识别和全文搜索
- 阅读进度自动保存与继续阅读
- 基于内容指纹识别书籍，文件改名或移动后可继续关联原阅读数据
- 书架搜索、排序、阅读状态筛选与批量管理
- 字体、字号、行距、段距、字距、页边距和文字透明度设置
- 纸白、护眼、夜间三种阅读主题
- 正文简体 / 繁体离线转换（不修改源文件）
- 独立书签、三色高亮、笔记编辑、Markdown 与分享图导出
- 书架分类、自定义封面、窗口置顶、沉浸阅读与老板键（F10）
- 文件拖放导入、Windows“打开方式”、窗口最大化与双击标题栏
- 全书搜索最多展示 5000 处匹配，达到上限时会明确提示
- 防剧透资料回顾：选中人物、物品、地点、组织、能力或事件名称后，通过右键菜单总结此前已读内容
- 每本书独立的“设定集”面板，可按人物、物品、地点、组织等类型筛选，并按势力、持有者或上级区域自动分组
- 关系索引会在两侧同步呈现：人物页能看到其物品与所属势力，物品和地点也保留在各自的完整索引中
- 人物卡详细整理与主角的关系、初识经过、关系网和身份；物品卡整理归属、获得经过与用途；地点卡整理位置、内容、相关人物与事件
- 主名称、昵称、外号与简称关联；支持人工合并、拆分别名和锁定“并非同一对象”的纠正规则
- 同一资料只在更后阅读进度再次查询时更新，不会读取未来章节
- 书架首页 AI 设置，支持 Kimi 和 OpenAI Chat Completions 兼容接口、多个供应商方案、模型拉取与手动模型设置
- AI 请求错误诊断，显示请求阶段、HTTP 状态码、错误码、空回复、审核响应与输出截断
- 阅读数据导入、导出和自动备份

## 数据与备份

阅读进度、笔记、分类、自定义封面、每本书的设定集和人工身份规则保存在 Electron 的 Windows 用户数据目录下：

```text
%APPDATA%\<应用名称>\data\reader-data.json
```

应用写入数据前会在同目录的 `backups` 文件夹生成备份，并保留最近 10 份。书架顶部的导入/导出按钮可以生成可迁移的 JSON 备份。

AI 供应商配置另存于同一数据目录的 `ai-settings.json`。API Key 使用 Electron 调用 Windows 系统安全存储加密；界面只能看到“已保存”状态，无法读回 Key。阅读数据导出不会包含 API Key。供应商 URL 默认必须使用 HTTPS，仅本机 `localhost` / 回环地址允许 HTTP；应用会拒绝携带 Key 的 HTTP 重定向。

“查看资料”会把已读范围内命中的片段、已确认的名称关联规则和所选名称发送到当前 AI 供应商。该功能不会进行外部资料检索。不同供应商如何保存和处理请求数据，取决于用户选择的供应商政策。

从书架移除书籍或删除源文件时，笔记、书签和进度不会被静默删除；孤立笔记仍会出现在笔记库中，并可继续编辑或导出。

从旧版本升级时，应用会自动把原有 `localStorage` 数据迁移到新的磁盘存储中。

> 阅读器不会复制原始 TXT / EPUB 文件。文件在已扫描目录中改名或移动后，刷新书架即可重新识别；目录外的文件可在“整理书籍”中选择“重新定位”。

## 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `←` / `A` | 向左翻页 |
| `→` / `D` | 向右翻页 |
| `F11` | 切换沉浸阅读 |
| `F10` | 隐藏/恢复窗口（老板键） |
| `+` / `-` | 调整文字透明度 |

## 本地开发

需要 Node.js 22 或更高版本。

```powershell
corepack enable
pnpm install
pnpm test
pnpm run dev
```

构建前端：

```powershell
pnpm run build
```

构建 Windows 便携版 EXE：

```powershell
pnpm run dist
```

构建结果位于 `release/MoyuReader-版本号.exe`。

## 项目结构

```text
electron/    Electron 主进程、文件读取、持久化与系统窗口接口
src/         React 界面和 TXT / EPUB 阅读器
assets/      应用图标
test-*       大文本分块、多编码、繁简转换与资料身份规则回归测试
```
